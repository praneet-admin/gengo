# Support

Gengo is free and run by one person, so support is designed to work while nobody is watching.

**1. Self-serve (instant)**
- In the app: **Help** (laptop header) or **☰ → How to use Gengo** (phone) → instructions, guided tour, keyboard shortcuts.
- [GUIDE.md → Troubleshooting & FAQ](GUIDE.md#17-troubleshooting--faq): mic, voices, slow dictionary, translation quota, quiz locked, old version, offline.
- Reset everything: browser console → `Gengo.resetState()`.

**2. Report a problem (asynchronous, answered within 48 h on weekdays)**
- In the app: **Help → Report a problem**. It opens a GitHub issue with your browser, device, app version and settings already filled in — you only describe what happened.
- Or file directly: https://github.com/praneet-admin/gengo/issues/new/choose

**3. Complaints**
If Gengo wasted your time, say so in an issue with the label `bug` and the word "complaint" in the title. Those are read first. You'll get a reply, a fix or a clear "won't fix, here's why" — not silence.

**What we don't do**: phone/WhatsApp support, account recovery (there are no accounts — your data is in your browser), or changes to the free public APIs Gengo depends on.
